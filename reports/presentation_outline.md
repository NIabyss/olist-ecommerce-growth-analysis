# 5 分钟项目讲解提纲

1. **背景（30 秒）**：把增长放缓拆成新客、复购、频次和客单价四个维度，而不是只看 GMV 总量。
2. **数据建模（60 秒）**：使用订单为事实粒度，商品和支付先聚合；用 `customer_unique_id` 而非订单客户 ID 识别复购。
3. **方法（90 秒）**：SQL 用 CTE、窗口函数计算首购和 cohort；Python 固化清洗、RFM、留存、统计检验；BI 用三页分别服务总览、用户增长和运营诊断。
4. **发现（90 秒）**：展示增长拆解结果、RFM 收入集中趋势、交付时效与评分的关联；明确相关不等于因果。
5. **行动（60 秒）**：履约治理、高价值保护、唤回实验；每项先写清假设和 GMV 公式，再通过随机实验验证。

## 项目核心产出总结

- 使用公开 Olist 电商数据设计订单粒度分析模型，编写含多表 JOIN、CTE、窗口函数的 SQL，覆盖 GMV、首购/复购、RFM 与 cohort 留存口径。
- 以 pandas 构建可复用清洗、质量检查、用户分层与留存分析管道，并实现固定随机种子的模拟 A/B 检验及置信区间输出。
- 设计 Tableau 三页仪表盘数据集与字段映射，形成增长拆解、履约诊断和策略影响测算框架；模拟结果与真实结果严格区分。

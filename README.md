# 电商经营增长诊断与用户复购提升

> 基于 Olist 巴西电商公开数据集的端到端分析项目：从 9 张原始表出发，完成 SQL 多表建模 → Python 清洗与统计检验 → Tableau 三页仪表盘 → 业务策略报告全链路。核心命题：**当销售增长放缓时，缺口到底来自新客不足、老客不复购、频次下降还是客单价下滑？**

---

## 核心结论速览

> 数据状态：**OLIST_ACTUAL**（Kaggle 真实数据重跑，非模拟），截止下单日期 2018-08-29。

| 指标 | 数值 |
|---|---:|
| 有效订单 / 用户 | 96,478 笔 / 93,358 人 |
| 观察窗 GMV | R$ 15,419,774 |
| 观察窗复购率 | **3.0%**（核心增长约束） |
| 2018-07 完整月 GMV | R$ 1,027,807（环比 +1.6%） |
| 高价值 RFM 用户 | 15,489 人，贡献 **29.7%** GMV |
| 逾期订单平均评分 | 2.57（未逾期 4.29，仅相关性） |

**三条关键发现：**

1. **增长动能有限但并非停滞** —— 2018-07 环比 +1.6%，三因子（活跃用户 × 每用户订单数 × 客单价）均微增，但乘法分解不等同于因果归因。
2. **低复购是最大结构性约束** —— 观察窗复购率仅 3.0%，高价值组平均频次也只有 1.14 单，二单转化空间显著。
3. **履约体验直接关联评分** —— 7,826 笔逾期订单评分 2.57 vs 未逾期 4.29，是优先级最高的体验杠杆（描述性关联，需实验验证因果）。

## 业务问题

当电商销售增长放缓时，缺口到底来自：
- 新客获取不足？
- 老客不复购？
- 购买频次下降？
- 客单价下滑？

在**没有营销成本、毛利、流量字段**的前提下，能给出多有把握的优先级建议？哪些结论必须留白？

## 分析框架

```
原始 9 表 → 订单粒度事实表(order_fact) → 三因子恒等式定位瓶颈
                                          ↓
                              ┌───────────┼───────────┐
                              ↓           ↓           ↓
                          RFM 分层    Cohort 留存   履约体验诊断
                              └───────────┼───────────┘
                                          ↓
                                  优先级策略 + 情景测算
```

**第一步（最关键）：** 把订单、商品、支付、评价按订单粒度聚合成事实表 `order_fact`，**杜绝一对多 JOIN 后直接求和导致 GMV 重复计算**。

**第二步：** 用「活跃用户数 × 每用户订单数 × 客单价」三因子恒等式定位增长卡在哪个环节，`identity_gap` 字段做恒等式自检（全月误差 ≈ 0）。

**第三步：** RFM 分层识别高价值人群、Cohort 分析留存结构、履约逾期诊断体验问题，逐层深挖根因。

**第四步：** 输出可检验的运营优先级，附 GMV 情景测算，明确标注假设与验证方式。

## 项目亮点

> 这三点是本项目区别于普通课程作业的核心差异化。

### 1. 数据严谨性：把"不出错"当作第一原则

- **订单粒度事实表**：先聚合再算 GMV，从根源规避一对多 JOIN 重复计算。
- **三因子恒等式自检**：每月 `identity_gap ≈ 0`，结果可验证。
- **质量门禁**：99,441 笔订单、112,650 商品行、103,886 支付行均无重复主键；客户关联、已交付金额、交付时间、事实表唯一性检查全部 0 异常，输出 `data_quality.csv`。
- **不完整月标记**：2018-08 非完整自然月，`is_complete_month` 字段显式标记，趋势分析默认排除。

### 2. 结论边界清晰：真实观察 / 假设测算 / 模拟实验三者严格分离

- **真实观察结果**：GMV、复购率、RFM 分布、逾期与评分相关性——基于真实数据。
- **假设情景测算**：P0/P1/P2 策略的 GMV 增量——明确标注公式、假设人群、未扣成本，不是 ROI 或收入预测。
- **模拟 A/B 实验**：因数据集无真实曝光/分组字段，用代码模拟分组实验演示比例差 z 检验、95% CI、近似 MDE——**明确标注不能作为真实营销效果证据**。

> 模拟 A/B 结果：对照组 46,835 人 / 实验组 46,523 人，模拟差异 +1.91pp，95% CI [1.51pp, 2.31pp]，p < 0.001，近似 MDE 0.57pp。

### 3. 工程化交付：可复现、可审计

- 提供**真实数据运行**与**模拟演示**两套流程，clone 后无原始数据也能跑通全链路。
- 模拟结果标记 `SIMULATED_DEMO`，切换真实数据必须重跑并通过质量检查，不能只改标签。
- 完整的数据字典、指标口径、项目复盘与自我审阅记录见 `docs/`。

## 策略建议与 GMV 情景测算

> 以下为同一观察窗内、未扣成本的 GMV 情景值，**不是年化收益、收入预测或 ROI**；三项不可直接相加（目标人群可能重叠），须以对照组识别增量。

| 优先级 | 策略 | 核心假设 | 观察窗 GMV 情景 | 验证方式 |
|---|---|---|---:|---|
| **P0** | 治理逾期履约 | 7,826 笔逾期中 20% 因体验修复产生额外购买 × 未逾期 AOV 158.69 | R$ 248,379 | 按物流/品类分层，做履约试点 |
| **P1** | 高价值用户关怀 | 15,489 人中 8% 增加一单 × 高价值组均额 258.92 | R$ 320,837 | 扣除权益成本，留出组测增量 |
| **P2** | 需唤回人群小流量实验 | 32,020 人中 5% 额外购买 × 全样本 AOV 159.82 | R$ 255,883 | 随机实验验证，防自然购买前置 |

## 数据边界与坚持的原则

1. **先聚合订单事实表，再算 GMV**——不做一对多 JOIN 后直接求和。
2. **真实观察 / 假设测算 / 模拟实验三者严格分开标注**——不混着说。
3. **没有流量、成本、毛利和真实实验数据时，不声称因果关系或 ROI**。
4. **乘法分解不是因果归因**——三因子恒等式用于定位，不用于分配贡献。
5. **不完整月、未成熟 Cohort、缺失评价**——均显式标记，不混入趋势结论。

# 指标口径

- **GMV**：已交付订单的商品金额加运费；取消/不可用订单不计入。这是商品成交口径，不等同于实收；`payment_value` 可有多支付行，只用于支付方式分析，若需实收必须单独聚合并对账。
- **订单量**：已交付订单数（`COUNT DISTINCT order_id`）。
- **用户数**：已交付订单对应的去重 `customer_unique_id`。
- **客单价（AOV）**：GMV / 订单量。
- **新客**：用户首笔已交付订单发生在当月；**复购用户**：当月下单且此前已有已交付订单的用户。
- **复购率**：观察窗内订单数 ≥2 的用户 / 有已交付订单用户。它不是新客次月留存。
- **Cohort 留存**：某首购月 cohort 在第 N 个自然月有至少一笔已交付订单的用户数 / cohort 首购用户数。
- **增长三因子**：GMV = 活跃用户数 × 每活跃用户订单数 × 客单价。环比变动用于定位，不是三项各自的因果贡献，也不应直接相加。
- **RFM**：R=分析截止日距最近购买天数（低更好）；F=订单数；M=GMV。五分位打分受样本离散度影响，样本小/单次购买比例高时应结合业务阈值。
